# Split View

Open two or more files. Right-click a tab and choose **Split View**, then
**Vertical (Side by Side)** or **Horizontal (Top and Bottom)**, and the other
file to display. Unsaved documents are available too.

Click inside a pane to make it active. Editing commands, save, undo/redo,
search, word counts, and the outline follow the active file. Selecting an
already visible tab activates its pane; selecting another tab replaces the
file in the active pane. The file selector above each pane also lets you
choose another open document.

Drag the divider to resize the panes. With the divider focused, use the arrow
keys to resize in steps; double-click it to restore equal sizes.

Choose **Close Split View** from the tab menu, or use the × button above the
pane you want to keep. Both files stay open. Closing either displayed tab
also returns to a single pane displaying the other file. The normal save
prompt still applies to unsaved tabs; cancelling it keeps the split open.

Split View works in rendered Markdown and Source Code modes. Relative image
paths resolve against each document's folder independently. The split layout
lasts for the current window session.
